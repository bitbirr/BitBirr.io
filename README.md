# BitBirr.io

**Your Gateway to Crypto in Ethiopia** 🇪🇹

BitBirr is a comprehensive cryptocurrency exchange platform designed specifically for Ethiopian users. Buy Bitcoin, Ethereum, and USDT using Ethiopian Birr (ETB) through trusted local payment methods.

## 📱 Mobile App (Flutter)

The complete Flutter mobile application for Android is available in the `flutter_app/` directory.

### Features

✅ **Buy Cryptocurrency**
- Bitcoin (BTC)
- Ethereum (ETH)
- Tether USD (USDT)

✅ **Ethiopian Payment Methods**
- Telebirr
- CBE Birr
- Awash Bank

✅ **User Features**
- Email OTP authentication
- Real-time exchange rates
- Order tracking and history
- Support ticket system
- Secure wallet integration

### Technology Stack

- **Frontend:** Flutter (Material 3 Design)
- **Backend:** Supabase (Auth, Database, Storage)
- **State Management:** Provider
- **Platform:** Android (iOS-ready)
