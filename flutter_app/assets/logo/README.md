# BitBirr Logo

This directory should contain the BitBirr logo files.

## Required Files
- `logo.png` - Main logo (512x512px recommended)
- `logo_white.png` - White version for dark backgrounds

## Icon Files
Place launcher icons in the appropriate Android mipmap directories:
- android/app/src/main/res/mipmap-hdpi/ic_launcher.png (72x72)
- android/app/src/main/res/mipmap-mdpi/ic_launcher.png (48x48)
- android/app/src/main/res/mipmap-xhdpi/ic_launcher.png (96x96)
- android/app/src/main/res/mipmap-xxhdpi/ic_launcher.png (144x144)
- android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png (192x192)

You can use tools like [App Icon Generator](https://appicon.co/) to generate icons from your logo.
